# YourWeddingsDJ — Event Portal

Single-page wedding DJ planner (`index.html`). Built with React 18 + Babel standalone loaded from CDN, backed by Supabase. No build step: open `index.html` in a browser or deploy the folder to any static host.

The Supabase key embedded in the page is the public `anon` key; access control relies on the project's row-level security policies.
